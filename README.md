# 💊 VMEDPharma

Aplicativo mobile para farmácia desenvolvido com React Native e Expo, oferecendo uma experiência completa de e-commerce farmacêutico.

## 📱 Sobre o Projeto

VMEDPharma é um aplicativo de farmácia que permite aos usuários navegar por produtos, fazer pedidos, rastrear entregas e gerenciar seu perfil de forma intuitiva e segura.

## ✨ Funcionalidades

- 🏠 **Tela de Início**: Navegação principal e acesso rápido
- 👋 **Tela de Saudação**: Boas-vindas personalizadas
- 🔐 **Tela de Login**: Autenticação segura de usuários
- 📝 **Tela de Cadastro**: Registro de novos usuários
- 🔍 **Tela de Pesquisa**: Busca avançada de produtos
- 💊 **Tela de Produto**: Detalhes completos dos medicamentos
- 🛒 **Tela de Carrinho**: Gestão de itens selecionados
- 💳 **Tela de Pagamento**: Processamento seguro de pagamentos
- 📦 **Tela de Rastreamento**: Acompanhamento de pedidos em tempo real
- 👤 **Tela de Perfil**: Gerenciamento de informações do usuário

## 🚀 Tecnologias

- **React Native** 0.76.9
- **Expo** ~52.0.47
- **React Navigation** (Stack Navigation)
- **React Native Paper** 4.9.2
- **Axios** (requisições HTTP)
- **Expo Vector Icons** 14.0.2

## 📋 Pré-requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn
- Expo Go (para testar no dispositivo móvel)
- Android Studio ou Xcode (para emuladores)

## 🔧 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/Victorkaue333/VMEDPharma.git
cd VMEDPharma
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor Expo:
```bash
npx expo start
```

## 📱 Como Executar

### No dispositivo físico:
1. Instale o app **Expo Go** na Play Store (Android) ou App Store (iOS)
2. Execute `npx expo start`
3. Escaneie o QR code exibido no terminal

### No emulador Android:
```bash
npx expo start --android
```

### No emulador iOS:
```bash
npx expo start --ios
```

### No navegador web:
```bash
npx expo start --web
```
